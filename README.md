# Lin’an imperial-city architectural ceramics: data and code

This repository provides the data and numerical verification code accompanying the study of component-associated compositional variation in architectural ceramics from the Southern Song imperial city of Lin’an.

Download `Linan_architectural_ceramics_data_code.zip` and extract it to access:

- XRF compositions and sample mapping for 11 fragments, oxide-ratio comparisons, sensitivity results, and CLR–PCA inputs and outputs.
- Twenty original XRD scans and their processed results; five original FTIR spectra and associated instrument plots.
- Twelve original SEM image fields used in Figure 6 and their sample/panel mapping.
- Specimen-level evidence, source references for literature comparisons, and Python code for numerical verification.

The archive contains a detailed README, data dictionary, environment requirements, and execution instructions. It includes numerical verification code; it does not contain figure-generation scripts. The archaeological source compilation and third-party full-text articles are not included.
